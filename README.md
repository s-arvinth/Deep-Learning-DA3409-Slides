# Fundamentals of Deep Learning — Lecture Slides

Beamer decks for *Fundamentals of Deep Learning*, all sharing one
custom theme.

## Two versions of every deck

Each class folder contains up to two self-contained variants:

| Subfolder | What it uses |
|---|---|
| `A_Textbook_Figures/` | figures taken from the textbooks (Rojas; Prince; Bishop & Bishop), reproduced with attribution |
| `B_Recreated_Figures/` | figures generated by our own scripts — worked examples computed from scratch, vector PDF, Fira Sans |

Both variants cover the same material. `B_` folders also contain a
`src/make_figures.py` that regenerates every plot.

```
Class02_Intro_Neural_Networks/
    A_Textbook_Figures/    main.tex  figs_official/  fonts/
    B_Recreated_Figures/   main.tex  figs/  fonts/  src/
Class03_Perceptrons_PLA/
    A_Textbook_Figures/    ...
    B_Recreated_Figures/   ...
Class05_Shallow_NN_Regression/
    A_Textbook_Figures/    ...
Class06_Shallow_NN_Classification/
    A_Textbook_Figures/    ...
Class07_Deep_Networks_Universal_Approximation/
    A_Textbook_Figures/    ...
    B_Recreated_Figures/   ...
```

## How to compile a deck

1. Open the variant you want, e.g.
   `Class03_Perceptrons_PLA/B_Recreated_Figures/main.tex`
2. **Menu -> Compiler -> XeLaTeX**  (required — the theme uses Fira Sans)
3. **Menu -> Main document ->** that `main.tex`
4. **Recompile**

Each subfolder is self-contained: it carries its own `figs/` and
`fonts/`. The shared theme lives at the project root and is found
automatically.

> **Why XeLaTeX?** The theme loads the bundled Fira font files, so the
> typography is identical everywhere regardless of what Overleaf has
> installed. This only works under XeLaTeX (or LuaLaTeX).

## Regenerating the figures (B variants)

```
cd Class03_Perceptrons_PLA/B_Recreated_Figures/src
python3 make_figures.py
```

Requires NumPy, Matplotlib and SciencePlots (`import sci_style`).
Figures are written to `../figs/` as vector PDFs.

## The shared theme

`beamer{,color,inner,outer}thememetropoliscustom.sty` at the project
root: maroon accents, indigo/maroon gradient title pages, yellow footer
bar, plus helpers (`redhighlight`, `\focus`, `\alert`) and the
two-cell comparison strip each deck defines near the top of its
`main.tex`.

Editing the theme once changes every deck.

## Collaborating

- **Share** (top-right) -> invite collaborators, or enable link sharing.
- **History** (Menu -> History) tracks every change.
- Convention: one variant per subfolder, theme at the root, each
  variant carrying its own `figs/` and `fonts/`.
