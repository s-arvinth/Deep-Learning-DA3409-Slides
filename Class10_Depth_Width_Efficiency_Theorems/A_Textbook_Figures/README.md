# Class 10 — textbook-figures variant

**Prince (2023), Fig. 4.9** (linear regions against parameters, for
`D = 1` and `D = 10`) is reproduced with attribution. CC BY-NC-ND,

the depth/width asymmetry, Poggio's compositional bound and the
