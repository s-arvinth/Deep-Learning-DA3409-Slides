MODIFICATIONS REQUIRED FOR THE FIGURE CODE
==========================================

Apply to every deck. Do not change the slides, the .tex files or the figure files.
Only reorganise the code that generates the figures.


1. For every figure that a deck loads with \includegraphics{<name>} and that was
   generated by code, there must be exactly one Python script named

       <name>.py

   where <name> is exactly the argument of \includegraphics, without the file
   extension, same spelling and same case.
   Example: \includegraphics[height=0.40\textheight]{error_surface}
            -> error_surface.py


2. Put the scripts for each deck in one folder named after the deck:

       figure_code/main_classN/<name>.py

   e.g. figure_code/main_class3/error_surface.py


3. Rename the code to match the figure, never the other way round. Figure file
   names and the \includegraphics lines in the .tex must stay as they are.


4. One script per figure. If a current script (e.g. make_figures.py,
   build_all.py) produces several figures, split it so each figure has its own
   <name>.py. A multi-panel figure that is saved as one file is one figure and
   gets one script.


5. Each <name>.py must run on its own:

       python <name>.py

   and write exactly the figure file the slide uses (<name>.pdf or <name>.png,
   whichever the deck loads), with the same data, parameters and style.
   Shared code (plot style, colours, common helper functions) may go in one
   helper file in the same folder, e.g. figure_code/main_classN/common.py,
   which the scripts import. Helper files are the only .py files in the folder
   whose names do not match a figure.


6. Fix every random seed inside the script, so running it again gives the same
   figure.


7. At the top of each script, add a short comment with:
     - the figure name and the deck(s) and slide title(s) where it is used
     - the Python packages it needs (e.g. numpy, matplotlib, scienceplots)


8. Figures that were not made by code need no script: textbook figures used as
   given, figures drawn with TikZ inside the .tex, and images taken from
   elsewhere.


9. Scripts that no longer produce any figure used in a deck can be moved to
   figure_code/unused/.


Example:

   main_class3.tex uses  \includegraphics{error_surface}  and  \includegraphics{pla_run}
   main_class6.tex uses  \includegraphics{sigmoid}

   figure_code/
     main_class3/
       common.py             shared style and helpers
       error_surface.py      writes error_surface.pdf
       pla_run.py            writes pla_run.pdf
     main_class6/
       common.py
       sigmoid.py            writes sigmoid.pdf
