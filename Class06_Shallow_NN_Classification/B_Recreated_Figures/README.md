# Class 6 — recreated-figures variant

All 14 figures in this deck are generated by `src/build_all.py`; there
are no textbook images. See `src/README.md` for the module-by-module
map and `../../_shared/FIGURE_SOURCES.md` for the conventions.

```bash
cd src && python3 build_all.py
cd ..  && xelatex main.tex && xelatex main.tex     # twice
```
