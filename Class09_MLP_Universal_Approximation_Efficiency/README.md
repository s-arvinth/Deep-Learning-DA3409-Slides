# Class 9 — MLP/FNN to Universal Function Approximation

Part one of a two-lecture pair with Class 10. This deck answers **what a
network can represent, and at what rate**:

* the curse of dimensionality for fixed basis functions
* universal approximation (Cybenko, Hornik, Leshno)
* rates — Barron (1993) and the DeVore–Howard–Micchelli lower bound
* width as a **threshold** (Lu et al.; Hanin & Sellke / Johnson)

It deliberately stops there. **Depth versus width — the sawtooth,
Telgarsky, Eldan–Shamir, Cohen, Safran, Liang & Srikant, Lu's width
efficiency, Vardi, Montúfar, Serra, the VC bound and Poggio's
compositional escape — is all Class 10.** Nothing is covered twice.

Three variants, as usual: `A_` textbook figures, `B_` recreated figures,
`C_` recreated figures with the results absent from both textbooks
removed.
